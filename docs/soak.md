# 单机长时运行验证

`scripts/run_soak.py` 在独立端口和数据库上启动真实 FastAPI 服务，连续运行合成采集并读取工作台状态。启动前要求测试脚本已经提交，将 HEAD 提交封存到输出目录；未提交的产品改动不会进入测试，后续开发不会改变测试代码。默认工作台和模型服务不参与测试。

```bash
.venv/bin/python scripts/run_soak.py run --output artifacts/soak-8h --port 8504
```

默认持续 8 小时，每 10 秒检查一次。`report.json` 持续更新心跳、进程标识、提交、固定门槛与资源峰值；`server.log` 保存服务错误。可用终端后台任务或系统任务管理器运行；向报告中的 `runner_pid` 发送正常终止信号会中止测试并关闭它创建的 API 服务。不要用报告中的历史 PID 停止其他进程。

固定门槛为：采集不能自行停止，停滞不超过 30 秒；状态响应不超过 2 秒；历史窗口不超过 300 帧；API RSS 不超过 1.5GiB，十分钟预热后的增长不超过 256MiB；单进程 CPU 不超过两个核心；测试目录不超过 1GiB，磁盘剩余不少于 2GiB。资源检查只包含隔离 API，不包含其他应用或语言模型。失败即停止负载并保存原因。

退出时检查服务正常关闭、子进程结束、SQLite 完整性与所有事件 JSON 可读。短时运行只标为 `smoke_only`；心跳更新的 `running` 也不代表验收通过。只有完整时长、资源门槛与退出检查全部完成才标为 `passed`。休眠、进程中断或系统负载导致失败时保留报告，用新目录重测。

此测试覆盖合成连续采集和 API 读负载。它不证明摄像头、真实视觉、模型推理、备份恢复、磁盘耗尽处理或证据保留策略已通过；完整 P0 门槛仍见 [ROADMAP](../ROADMAP.md)。
