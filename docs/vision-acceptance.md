# 视觉研发验收

三个模块共用版本固定的 `vision-research-v1` 门槛，定义见 `src/acceptance.py`。指标不达标保持 `failed`，样本不足保持 `insufficient_evidence`；工程测试通过不替代效果验收。门槛是本轮研发目标，尚未由工位误报成本或漏检损失确定生产标准。

| 模块 | 必须交付 | 效果通过门槛 |
| --- | --- | --- |
| 1：误差分析与方法对照 | 原图／对齐 PaDiM、正常数据限定的 ROI、非空间正常 patch 记忆对照；FP/FN 热点与姿态分组 | 至少正常／缺陷各 30 张；总体召回 ≥90%，正常误报 ≤10%，总体及每类覆盖 ≥98%；每个声明的姿态组正常／缺陷各 ≥10，并满足相同效果门槛。观察数据只支持开发诊断。 |
| 2：独立最终集 | 未观察类别预划分、验证集选择、代码与参数冻结、最终集单次消费记录 | 数据身份及归一化像素无交叉；独立最终集正常／缺陷各 ≥30；满足上述总体效果门槛，不在最终结果出来后改阈值再报同一集。 |
| 3：真实成像条件 | 真实公开多域数据入口、固定配方跨域评估、现场验收缺口 | 各真实域正常／缺陷各 ≥30，满足总体门槛；相对原始域召回下降 ≤10 个百分点。软件变换不能通过真实域门槛；公开数据不能代替固定工位实测。 |

召回使用全部计划缺陷作分母，包括推理失败；正常误报使用成功的正常图，同时单独约束每类覆盖率。报告保留 TP/TN/FP/FN、两类不可用数、样本数和 Wilson 95% 区间。点估计门槛通过不表示区间下界达到生产要求。重复根身份与软件派生图不能增加独立支持数。

## 开发对照

```sh
python scripts/compare_visual_methods.py --output artifacts/method-comparison-pcb1
```

沿用已观察 PCB1 的 120 张评估图；正常训练前 40 张拟合、后 20 张标定，95% higher 分位固定阈值。ROI 从对齐后的正常拟合图蓝色板区域确定包围矩形，固定边距 20px，不读取缺陷掩码或测试标签，可能遗漏板外缺陷；是检验背景热点的候选假设。Patch memory 使用同一 ResNet18 特征，14×14 池化，seed=0 抽取最多 4096 个正常 patch，最近邻距离及 Gaussian σ=4 平滑；不包含 PatchCore 的 coreset／重加权，不能称完整 PatchCore 复现。所有候选独立实现，未复制外部代码，也未接入实时默认检测器。

结果保留模型统计、固定正常标定分数、逐图判定、错误分组和最多 12 张错误热点示意。热点是异常分数位置，无像素级缺陷真值时不能解释为正确缺陷定位。

2026-10-09，macOS arm64、CPU、固定 ResNet18 权重实测，正常／缺陷各 60 张：

| 开发候选 | 全部缺陷召回 | 正常误报 | 覆盖 | 总体门槛 |
| --- | --- | --- | --- | --- |
| 原图 PaDiM | 95.0% | 58.3% | 100% | 未通过 |
| 对齐 PaDiM | 50.0% | 3.3% | 100% | 未通过 |
| 对齐 ROI PaDiM | 90.0% | 25.0% | 100% | 未通过 |
| 原图 patch memory | 93.3% | 55.0% | 100% | 未通过 |
| 对齐 patch memory | 21.7% | 1.7% | 100% | 未通过 |

ROI 版使用自己的正常标定阈值，因此召回提升不能解释成删背景本身的纯收益。对齐全图的最大热点在 ROI 外有 26/120 张，其中正常 15 张、缺陷 11 张；错误预览也存在背景热点。结果支持背景影响标定的假设，同时 ROI 的 25% 误报仍不达标。简单非空间记忆未解决问题；没有理由替换实时默认算法或声称完整 PatchCore 无效。近参考方向仅 4 张缺陷，分组支持也不足。

## 独立最终评估协议

PCB1 的异常测试图均已观察，因此新协议使用未观察的 PCB2。先按官方身份的固定 SHA 排序，每类 100 张测试图分成验证 50 张／最终 50 张；正常训练固定 40 拟合／20 标定。划分时核对全部文件摘要和归一化像素，包括已观察 PCB1；计算摘要不做最终预测或可视化。跨类别须重新拟合该类别正常图，不能报告为 PCB1 模型的零样本迁移。

```sh
python scripts/prepare_visa.py --category pcb2 --train 60 --normal 100 --anomaly 100 --output data/public-datasets/visa-pcb2-sealed
python scripts/validate_visual_release.py partition --source data/public-datasets/visa-pcb2-sealed --protocol artifacts/pcb2-release-v1 --observed-source data/public-datasets/visa-pcb1-expanded
python scripts/validate_visual_release.py validate --source data/public-datasets/visa-pcb2-sealed --protocol artifacts/pcb2-release-v1
python scripts/validate_visual_release.py freeze --source data/public-datasets/visa-pcb2-sealed --protocol artifacts/pcb2-release-v1
python scripts/validate_visual_release.py final --source data/public-datasets/visa-pcb2-sealed --protocol artifacts/pcb2-release-v1
```

验证阶段明确使用验证标签选择阈值：遍历固定模型的验证分数切点，在满足效果门槛的候选中先最小误报、再最大召回，平局按固定方法顺序选择。原正常标定结果仍保留；这是有标签的研发选择，不冒称正常数据独立决定最终阈值。若无人通过，不冻结、不消耗最终集，也不声称方法有效。

冻结保存统计、正常参考、可选 ROI、阈值、完整方法源码快照和代码／权重／依赖版本／划分／验证报告摘要。最终推理只加载这份统计，不重新训练或标定；全部预测完成后才拼接标签。划分或配方被修改会拒绝执行。首帧最终预测前以排他创建写入源目录的 `final-consumed.json`，换报告目录不能绕过消费记录；中断也留 `aborted` 并拒绝重试，避免选择性报告。该机制防误操作，不是对本地文件所有者的访问控制；复制数据、删除记录或隐瞒观察历史仍可能破坏独立性。新的算法迭代需要另留未观察数据。

2026-10-09，同一 CPU 环境，PCB2 验证集仅 ROI PaDiM 通过阈值选择后的门槛（召回 92%、误报 8%、覆盖 100%）。冻结阈值 15.568836212158203 后，最终 100 张得到 TP/TN/FP/FN = 44/44/6/6：召回 **88%**、误报 **12%**、覆盖 **100%**，效果验收 **未通过**。召回 Wilson 95% 区间 76.2%–94.4%，误报区间 5.6%–23.8%。保留失败结论，不在同一最终集降低门槛或调整阈值。协议报告在忽略的 `artifacts/pcb2-release-v1/`，源目录已有最终集消费记录；这批最终图已观察，后续不能再次称盲测。

## P1 方法扩展与 PCB4 单次评估 — 2026-10-10

增加两组固定研发候选：PaDiM 协方差的 90% 对角收缩，降低少量正常样本估计高维协方差的不稳定性；28×28 patch memory 使用正常拟合特征的逐通道标准化、固定 seed=0 的 4096 patch 记忆与 σ=2 平滑。最近邻查询每批不超过 128 个 patch，封存加载核验字段、展开大小与正常尺度。这些候选没有接管工作台默认检测器，也不称完整 PatchCore。

先在已观察 PCB1 的 120 张图及 PCB2 原验证集的 100 张图上对照，未重新消费 PCB2 最终集。PCB1 无候选同时达到召回／误报门槛；PCB2 标签选择阈值后，对齐 ROI 收缩版为 92% / 8% / 100%，与原版持平；更密的标准化 patch 未胜出。此结果不支持算法提升声明。

PCB4 事先声明 PCB1、PCB2、PCB3 已观察来源，按原协议划分 40 张正常拟合、20 张正常标定及正常／缺陷各 50 张验证、各 50 张最终图。共比较 11 个固定候选；验证选择仍由先最小误报、再最大召回、最后固定方法顺序决定。原有对齐 ROI PaDiM 胜出，冻结阈值 **13.790014266967773**，验证召回 100%、误报 0%。

独立最终集一次消费得到 **TP/TN/FP/FN = 48/45/5/2**：召回 **96%**、正常误报 **10%**、覆盖 **100%**，通过既有点估计研发门槛。召回 Wilson 95% 区间 86.5%–98.9%，误报区间 4.3%–21.4%；误报恰在允许上限，不能称稳健生产标准。该模型在 PCB4 正常图上重新拟合，不是 PCB2 模型跨类别迁移，也不能用两类结果之差宣称算法改善。PCB2 的 88% / 12% 失败结论继续保留。

设备为 Apple M4 / 24GiB，CPU 推理，torch 2.8.0 / torchvision 0.23.0，固定 ResNet18 权重。原始模型、方法源码快照、预测及消费记录位于本地 `artifacts/p1-pcb4-release/` 与 `data/public-datasets/visa-pcb4-p1-sealed/final-consumed.json`。最终报告文件 SHA-256 为 `89128141670a4b8377d35856e9f632ffc6a15c46657476466313f106c6c0f222`，配方文件 SHA-256 为 `c05231368afe8a3d04a1ad91a2cd682dad13844f8d2ef2287432ee0c49f8e16a`。本轮没有最终集姿态分组、真实成像域、像素定位或工位验收；冻结研发配方与可部署实时配方仍分开。

## 真实成像条件

官方 MVTec AD 2 下载页当前提供直接类别归档；本轮使用最小的 vial 类别，未克隆仓库。`scripts/fetch_mvtec_ad2.py` 固定 URL、812067164 字节及 ETag `"67e6a011-3067295c"`，逐段核验 HTTP 206／Content-Range／ETag 并缓存摘要。完整本地 SHA-256 为 `002d8671479ee935657cc72207f7be98bdf13e7051b2485588d7afe80e59d9ec`，标识实际下载字节，不冒称供应商签名摘要。数据仅供非商业研究，CC BY-NC-SA 4.0，不随源码分发。

```sh
python scripts/fetch_mvtec_ad2.py
python scripts/prepare_mvtec_ad2.py
python scripts/run_domain_study.py --source data/public-datasets/mvtec-ad2-vial-public --output artifacts/mvtec-ad2-vial-domains
```

准备入口读取归档中明确的公共 `good/bad` 图与对应缺陷掩码，核验摘要、尺寸、路径和重复像素；不将 tar 任意路径解压到磁盘。使用前 40 张 train/good 拟合、前 20 张 validation/good 正常标定。私有图与私有标签不进入实验；未调用外部评测服务器。所有公共照明视图进入评估，保留 `good/bad` 与场景编号构成的根身份，跨照明配对只比较判定翻转，不增加独立场景数量。

域门槛要求每域正常／缺陷各 ≥30、召回 ≥90%、误报 ≤10%、总体及每类覆盖 ≥98%，以及相对参考域召回下降 ≤10 个百分点。软件变换与测试夹具不能获得真实域通过状态；每域重复根身份拒绝增加支持数。公开域通过也不表示固定工位通过。
