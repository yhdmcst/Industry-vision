# Graphite 工作台

Spark Guard 使用 React、TypeScript 与 Recharts 实现本地工业视觉旁路工作台。图像与测量证据优先，模型假设和人工结论分别呈现，不提供生产设备控制。

## 页面与状态

- **监测工作台**：当前与基线图像、测量指标、规则变化、可切换趋势、单帧采样、定时监测、事件标记。后台持续采集，切换页面不暂停；暂停按钮明确终止采集。
- **事件复核**：规则变化自动留存事件，也可人工标记。冻结当前、前一帧及基线图像，保留来源与扰动标签；支持历史会话、人工核验与事件 JSON 导出。人工核验不依赖模型。
- **基线与漂移**：基线版本、逐样本指标分布、当前窗口对照、配准可靠性、重建与重置。分布对照是描述性分析，不声称统计显著性。
- **设置与演示**：合成样本、摄像头或本地视频路径，七类软件扰动，无基线取景预检、批次留存与独立标注、固定数据集发布与会话证据导出。
- **本地模型**：官方 1.7B／4B 资产状态、准备、启停／重启、真实推理自检、验证后切换／回滚与运行策略；视觉模型校验登记、版本选择、加载／重载和保存配置恢复。故障提供恢复建议；日志和连接设置位于折叠维护详情。只停止本应用创建的服务；复核在途时禁止切换与启停。
- **回放评估**：历史回放、标签覆盖率与混淆矩阵、批次／来源分组、逐样本图像核对及同条件版本对比。报告按请求取证据快照，通过“刷新报告”纳入新采样；查询不触发采样或推理。

默认合成 PCB 无需摄像头或模型。图像由 DummyCamera 生成，指标由真实视觉链路计算；没有伪造的模型输出。故障保留错误，窗口预热保留“证据不足”，重建基线不会改写历史事件。

监测与基线页面展示告警周期、连续异常与恢复计数；基线页面另列逐帧质量门和拒绝原因，失败保留旧基线。事件详情区分初始冻结证据、周期内新增证据、规则恢复和切换导致的终止，人工结论单独保留。见[基线与告警可靠性](reliability.md)。

## 前后端职责

- React 管理页面、表单、筛选、图像放大与图表交互；约 900ms 轮询状态，历史未变化时省略曲线数据，事件列表按版本刷新，事件详情约 1.5s 刷新。离线时保留最后数据并明确提示可能过期。
- FastAPI 每个进程管理一个本地工作站。采集、基线及模型任务在锁保护下修改；GET 查询不触发采样。只使用一个 worker。
- 所有浏览器标签共享同一采集会话与设备。关闭浏览器不停止后端采集；必须点“暂停监测”或关闭服务。
- 生产模式由 FastAPI 同源提供 `frontend/dist` 和 `/api`；开发模式由 Vite 将 `/api` 代理到本地后端。没有外部字体、CDN 或云端推理请求。
- 当前为本机单用户工具，无身份认证与多工位隔离。历史事件保留冻结图像，实时页呈现最新画面；趋势选点只选择历史指标，不冒充历史图像。

## 配色

## 验收

`tests/test_api.py` 验证 API、采集生命周期、事件与错误边界；`scripts/test_ui.py` 验证真实浏览器交互、下载和 390px 布局。默认浏览器验收不调用模型，真实模型须显式传入 `--model-review`。新证据写入 `artifacts/ui-react/`，不覆盖历史 Windows 模型截图。

基线与告警专项使用 `scripts/test_reliability_ui.py`，覆盖候选拒绝、旧基线保留、周期去重、连续恢复、新增证据导出、视频结束和检测缺失；证据写入 `artifacts/ui-reliability/`。

采集专项使用 `scripts/test_acquisition_ui.py`，覆盖无基线预览、保存当前像素、独立标注、不可变发布与回放、失败反馈和 390px 布局。操作流程按采集源、预检留存、样本回放组织，详见[采集说明](acquisition.md)。

跨批次编排位于采集和样本回放之间，按来源选择、图像核对、参考／评估列表、发布前检查组织。检查后的表单或源记录变化会失效；发布生成固定版本，不切换会话。`scripts/test_composition_ui.py` 验证过期检查拒绝与根身份保留；公开图像另用 `scripts/test_public_data_ui.py --manifest <清单>` 验证，不自动下载数据或调用模型。

## 用户展示约定

主屏呈现任务、当前状态和下一步操作；实现名称、摘要、进程号和原始 JSON 收入追溯／维护详情。合成来源、失败、未知、证据不足和质量门槛保留可见，不因精简界面隐藏。界面移除开发版本与英文内部阶段标签，模型职责分开展示。

本地模型页将部署文件、服务连接、模型驻留和推理自检分别呈现，注明周期探测或最近检查及时间。设备信息指运行 Python 后端的电脑，整机资源按采样时间展示，超过 15 秒标记待更新。文件检查和自检不是持续验证；状态概览突出下一步操作，未保存配置、在途复核及外部服务的操作限制可见。维护详情使用可读字段，完整技术状态仍可通过显式诊断包导出。
## 日常交互

事件复核的会话、筛选、选中事件和草稿保留在浏览器标签页；草稿按会话和事件隔离，后台刷新不覆盖输入。草稿未提交前不是证据，关闭标签页或禁用浏览器存储可能丢失；用户可主动清空。人工结论保存仍为追加记录。

监测和复核图像支持同步缩放、指针位置对照和重置。原始像素及各自比例保留，这种对照不构成几何配准。趋势选中帧按会话与基线查询初始事件及周期新增证据，支持进入关联事件；画面仍为当前采样。路径输入支持浏览后端电脑的目录及最近选择；选择不代表校验或导入成功，错误保留在操作入口。
