# 样本管理与可重复回放

数据集将参考基线、评估顺序、采集条件和独立标签组织为本地 JSON 清单。导入后保存归一化图像副本；每次回放建立独立会话，复用现有视觉测量、规则观测和事件复核链路。

默认使用参考残差检测代理，也可[导入外部质检结果](inspection-results.md)并在建立回放前选择固定版本。回放用于复现测量与规则结果，不代表真实缺陷识别能力，也不保证模型回答一致。

也可在工作台[预检并留存当前采集样本](acquisition.md)，独立标注后直接发布固定版本，无需手工编写清单。

参考和评估来自多个来源时，可使用[跨批次编排](composition.md)选择采集草稿或固定数据集样本。编排保存根来源 `lineage`，样本详情可核对原样本、来源 ID 与批次关联键；再次编排不重置身份。普通导入清单不接受自行注入 `lineage`。

## 快速体验

在项目根目录、已激活虚拟环境后执行：

```sh
python scripts/create_demo_dataset.py
```

脚本在 `data/demo-dataset/` 创建 10 个基线与 30 个评估样本，并打印清单绝对路径。所有样本均标记为合成；失焦、光照衰减单独记录为软件扰动。目录存在时拒绝覆盖，可用 `--output <新目录>` 指定位置。

1. 启动应用，在“设置与演示 → 样本管理与回放”输入清单路径并导入。
2. 按批次、分组浏览样本，检查图像和标签。
3. 暂停正在进行的监测，等待模型任务结束，点击“建立回放”。
4. 使用“回放下一帧”或“连续回放”；也可在监测工作台采样。切页不影响后台回放。
5. 完成后自动暂停；导出回放结果，再次建立同一数据集回放进行比较。

导入不改变当前工作站。成功建立回放后，基线由清单固定，不能临时重建基线或叠加软件扰动。切换回普通采集源后可恢复这些操作。历史会话与人工结论保留。

## 清单格式

清单使用 UTF-8 JSON，`schema_version` 为 `1`。以下展示单个样本结构；完整清单必须包含 **10–100 个基线样本、至少 1 个评估样本，总数不超过 500**。

```json
{
  "schema_version": 1,
  "name": "工位 A · 批次评估",
  "description": "固定取景下的参考与受控变化序列",
  "samples": [
    {
      "id": "batch-b-001",
      "batch": "batch-b",
      "split": "evaluation",
      "path": "images/001.png",
      "origin": "real",
      "perturbation": "none",
      "captured_at": "2026-10-08T10:00:00+08:00",
      "conditions": {"exposure": "manual", "fixture": "station-a"},
      "label": {"defect": "unknown", "cause": "unknown", "note": "待独立核验"}
    }
  ]
}
```

| 字段 | 约束 |
| --- | --- |
| `id`、`batch` | 必填、非空；样本 ID 在数据集内唯一 |
| `split` | `baseline` 或 `evaluation`；两组分别保留清单中的相对顺序 |
| `path` | 清单目录内的相对路径，使用 `/`；拒绝绝对路径、上级路径、越界符号链接和 URL |
| `frame_index` | 视频样本必填，零起始整数，最大 100000；图像样本省略 |
| `origin` | `real` 或 `synthetic`；这是导入者的来源声明 |
| `perturbation` | 默认 `none`；软件处理过的图像填写扰动名称，物理工况变化记录在 `conditions` 中 |
| `captured_at`、`conditions` | 可选采集时间及条件描述；未提供的内容不补造 |
| `label.defect` | `unknown`、`normal` 或 `defect`，默认 `unknown` |
| `label.cause` | `unknown`、`none`、`optical`、`illumination`、`mechanical` 或 `product` |
| `label.note` | 可选标签依据，不超过 2000 字符 |

基线不能含已标注的缺陷、异常原因或软件扰动；允许未标注的参考样本，基线有效性仍需操作者确认。同一文件或同一视频帧不能重复登记。不同文件即使像素相同，也不能据此视为独立统计样本；数据划分应结合批次与采集过程。

图像支持 PNG、JPEG、BMP、TIFF、WebP，最大 1600 万像素。视频支持 MP4、AVI、MOV、MKV、WebM、M4V 容器，实际编解码器取决于本机 OpenCV；按帧索引顺序读取并保存指定帧，不按播放时间猜测位置。清单最大 1 MiB，单个媒体最大 256 MiB，总媒体最大 1 GiB。

## 固定输入与结果比较

导入将图像统一缩放至 **640 × 480**，使用 `INTER_AREA`，保存无损 PNG。该方式与当前监测链路一致，会改变非 4:3 图像的比例，不用于尺寸计量。原文件摘要、归一化图像摘要、清单字段和样本顺序共同确定数据集 ID；内容或标签变化须重新导入，生成新版本。

数据保存在运行数据库同级的 `datasets/` 目录，默认 `data/db/datasets/`。数据集目录仅在完整导入后发布；重复导入相同内容复用同一版本。回放建立前校验全部图像，采样时再次校验当前图像。文件缺失或摘要不符时保留最后成功结果并停止，不跳过失败样本。

回放导出包含数据集清单、基线与评估样本 ID、窗口大小、规则阈值、测量源码摘要、Python/OpenCV/NumPy 版本，以及逐样本测量与结果摘要。未完成的回放同样可以导出，进度明确标识。“历史回放”保留最近 100 个会话中的回放入口，切换采集源或重启服务后仍可导出。结果摘要排除会话 ID、实际执行时间和耗时；相同环境、输入及配置下可用于比较重复运行结果。跨平台浮点结果仍可能存在差异。

导出不包含图像副本。换机复现需同时保留原始数据集及清单，重新导入，并检查数据集 ID 和配置摘要。模型回答、人工核验与运行耗时不纳入确定性比较。

## 标签与验证边界

批次、文件名、采集描述及独立标签保存在样本证据中，整体排除在模型快照之外。模型只接收测量指标与操作者主动填写的现场记录；进行盲测时也应避免在现场记录中泄露标签。

标签由导入者提供，不自动等同于真实缺陷或已验证根因。[回放评估](evaluation.md)可描述上游判定和规则与标签的匹配、覆盖率及版本差异，并按来源分组；不将软件扰动标签作为真实工况评估数据。

```sh
python -m pytest tests/test_datasets.py -q
python scripts/test_dataset_ui.py --url http://127.0.0.1:8501 --channel chrome
```

浏览器脚本只允许对专用合成工作站执行，会创建示例数据、切换回放会话并保存本地报告。
