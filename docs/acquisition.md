# 采集预检与样本留存

在没有基线或模型的情况下检查取景，按批次保存当前预览像素与采集记录，再独立标注并发布为固定回放数据集。入口为“设置与演示 → 采集预检与样本留存”。本模块不设置相机曝光、白平衡或焦距，不执行相机标定、训练或设备控制。

## 操作流程

1. 暂停监测，连接合成源、摄像头或本地视频。固定回放期间须先切回普通采集源。
2. 点击“采集预览帧”，检查图像、亮度、对比度和清晰度。预检不需要基线，不应用软件扰动，不修改监测帧、窗口、告警或恢复计数；读取会推进视频／设备的位置。
3. 创建采集批次，记录固定工装、参考工况和核验计划。选择参考或评估分组，填写当前采集条件，点击“留存预览样本”。
4. 查看已留存样本，独立填写缺陷标签、原因标签与依据。未知内容保持未标注，不根据模型结论自动补标签。
5. 至少留存 **10–100 个参考样本和 1 个评估样本**，总数不超过 **500**。点击“发布为回放数据集”，在下方“样本管理与回放”选择新版本并建立回放。

保存的是显示的当前预览，不会在点击留存时重新采一帧。预览在服务端单调时钟计时的 60 秒内可保存；重新预检、切换采集源、采样、开始监测或操作基线会使旧预览失效。同一帧不能在同一批次重复留存。预检失败清除旧图像并显示错误，不能以旧画面冒充成功采集。

参考样本复用[基线质量门](reliability.md)：平均亮度不大于 10、不小于 245、对比度小于 1 或指标非有限时拒绝。过暗、过曝和纯色帧可明确留为评估样本，但不能用作参考，也不能通过修改分组绕过质量门。通过取景质量门不证明基线稳定或产品正常。

## 来源与独立标签

参考与评估分属不同批次时，可在[跨批次编排](composition.md)直接组合草稿样本，无需先为每个批次凑齐两组。发布保留原采集批次 ID 和样本身份。

- 合成源强制 `origin=synthetic`；摄像头强制 `origin=real`，该字段只表示采集来源，不证明真实缺陷。
- 视频须声明为合成／测试或真实采集视频；声明由操作者负责，系统不推断视频来源。
- 页面留存时缺陷与原因均为 `unknown`。样本标注属于操作者声明，标签、批次和采集描述不进入模型快照。
- 预检不叠加软件演示扰动，留存记录 `perturbation=none`。物理工况变化在采集条件中记录。
- 重复像素摘要显示提示。多次采集固定合成画面可得到不同样本身份，不能据此认为它们是独立统计证据；盲测仍须隔离采集批次。

图像与监测链路一致，统一为 **640 × 480 BGR，INTER_AREA，PNG**，保留归一化像素，不保留原分辨率图像。非 4:3 画面会改变比例，不用于尺寸计量。源报告尺寸、曝光等读数依赖设备与 OpenCV 后端；非有限读数显示为空，零值不证明设备支持该属性。

## 存储与版本

采集草稿位于运行数据库同级 `acquisition/`，默认 `data/db/acquisition/`：

```text
<批次 ID>/
  batch.json
  <样本 ID>/
    sample.json
    image.png
```

记录包含图像 SHA-256、采集时间、固定采集序号、来源会话、基线 generation、设备读数、图像质量和独立标签。序号决定顺序，系统时钟回拨不会重排样本。预览仅驻留内存；显式留存会保存像素，服务重启保留草稿，但不恢复预览。

新增样本先完整写入临时目录，标注使用临时 JSON 原子替换。写入失败保留原草稿并返回错误；摘要不匹配的图像不能读取或发布。此机制未验证断电后的文件系统耐久性。

发布复用现有[数据集导入校验](datasets.md)，生成运行数据库同级 `datasets/` 下的固定版本，不切换采集源或当前会话。相同内容重复发布复用数据集 ID；修改标签、条件或样本后重新发布生成对应版本，旧版本保持不变。发布清单保留时间、标签、条件以及 `capture_source`、`capture_batch_id`、`capture_session` 关联；完整设备读数、质量指标与 generation 仍在草稿记录中，固定回放不重建设备现场状态。

每个样本允许 27 个自定义条件字段，另保留 3 个系统关联字段。自定义条件不能使用这三个系统字段名，API 会拒绝而非覆盖操作者记录。完整草稿和已发布数据均为本机运行数据，不纳入源码包；换机时须另行保留数据目录并复核像素中的现场信息。

## API 与验证

| 请求 | 用途 |
| --- | --- |
| `POST /api/acquisition/preview` | 暂停状态下读取预览及质量指标 |
| `GET /api/acquisition/preview/image?token=…` | 读取当前预览 PNG；替换或清除后的 token 返回 404 |
| `GET / POST /api/acquisition/batches` | 列出或创建批次 |
| `GET /api/acquisition/batches/{batch_id}` | 读取批次、按采集序号排列的样本 |
| `POST /api/acquisition/batches/{batch_id}/samples` | 留存预览；必填 `token`、`split`、`origin`，可填 `conditions`、`label` |
| `PATCH /api/acquisition/batches/{batch_id}/samples/{sample_id}` | 替换分组与标注；必填 `split`，省略的条件／标签恢复为空／未标注 |
| `GET /api/acquisition/batches/{batch_id}/samples/{sample_id}/image` | 校验摘要后读取留存 PNG |
| `POST /api/acquisition/batches/{batch_id}/publish` | 原子发布固定回放数据集 |
