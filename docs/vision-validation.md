# 视觉验证与实时接入

验证按姿态、成像条件、实时处理依次推进。公开图像、软件变换和工位采集分别记录；当前检测配置没有生产默认推荐。

## 姿态与未观察样本

```sh
python scripts/prepare_visa.py --output data/public-datasets/visa-pcb1-expanded --train 60 --normal 100 --anomaly 100
python scripts/run_pose_study.py
```

固定正常拟合 40 张、独立正常标定 20 张，保持上一轮参数。脚本按上轮清单的官方原文件身份排除已观察的 80 张测试图，并拒绝新评估图与既有评估／训练图的归一化像素重复。剩余正常与异常各 60 张先执行全部预测，再附上独立标签；已有实验目录拒绝覆盖。当前数据是算法分区，不证明工位批次独立。

对每张新图固定执行原图和 180° 旋转两种输入，不根据标签选方向。两种输入使用相同模型和原正常标定阈值；旋转图标为 `controlled_transform`，不是新增真实采集。原图版本可通过 `manifest.json` 和 `detectors/{raw,aligned}/inspection-results.json` 导入工作台；配对旋转的指标仅在独立报告中计算，不增加真实样本分母。

2026-10-09，macOS arm64、ResNet18／PaDiM CPU 实测：

| 120 张新增原图 | AUROC | TP / TN / FP / FN | 召回 | 正常误报 |
| --- | --- | --- | --- | --- |
| 原图模型 | 0.7703 | 57 / 25 / 35 / 3 | 95% | 58.3% |
| 对齐模型 | 0.9164 | 30 / 58 / 2 / 30 | 50% | 3.3% |

接近参考方向的原图有正常 28 张、缺陷 4 张；反向原图有正常 32 张、缺陷 56 张。这次各姿态组都有两类，但仍然不均衡：原图模型反向组 32 张正常图全部误报，组内 AUROC 0.6239；对齐模型该组 AUROC 0.8655、召回 51.8%、误报 6.25%。接近参考方向的缺陷仅 4 张，召回结果不能外推。

对每图旋转 180° 后，原图模型 33/120 个判定翻转，对齐模型 3/120 个翻转。该配对实验支持对齐降低方向敏感性，同时原始缺陷召回仍不足，不能把姿态稳定等同检测准确。没有依据这些测试结果调整阈值或自动改变反向摆放的工位语义。

结果位于忽略的 `artifacts/pose-study-pcb1/`，包括清单、两版真实结果、空间统计和 `pose-study.json`。这 120 张在本轮评估后已成为观察数据，后续优化须另留最终评估集，不能继续称它们为未查看的盲测集。

## 固定成像条件

导出包含固定权重、统计、参考图与摘要的本地模型，再对全部 120 张原图执行相同变换：

```sh
python scripts/export_vision_model.py --mode raw --output data/models/padim-pcb1-raw
python scripts/export_vision_model.py --mode aligned --output data/models/padim-pcb1-aligned
python scripts/run_condition_study.py --model data/models/padim-pcb1-raw --output artifacts/conditions-pcb1-raw-verified
python scripts/run_condition_study.py --model data/models/padim-pcb1-aligned --output artifacts/conditions-pcb1-aligned-verified
```

固定亮度乘 0.7／1.3、5×5 Gaussian 模糊和横向平移 12px（reflect padding）；不重新拟合、标定或按测试选择参数。变换仍有同一根图像身份，不增加独立真实样本数，也不是物理曝光、真实失焦或工位移动。

| 条件 | 原图模型召回／误报 | 对齐模型召回／误报 | 对齐不可用 |
| --- | --- | --- | --- |
| 原始 | 95% / 58.3% | 50% / 3.3% | 0/120 |
| 亮度 ×0.7 | 93.3% / 58.3% | 43.3% / 3.3% | 0/120 |
| 亮度 ×1.3 | 95% / 63.3% | 65.1% / 10.7% | 21/120 |
| 模糊 5×5 | 93.3% / 58.3% | 43.3% / 3.3% | 0/120 |
| 平移 12px | 98.3% / 71.7% | 45% / 1.7% | 0/120 |

表中召回／误报的分母为成功且有标签的样本。变亮对齐版失败包含 17 张缺陷和 4 张正常；其找到缺陷占全部 60 张缺陷为 28/60=46.7%，不能把可用子集的 65.1% 解释为收益。JSON 同时保留覆盖率、两类不可用数量、全部缺陷分母、逐图错误、规则观测和相对原始输入的判定翻转。

正常原图已有 17/60 张出现图像规则提示；变暗、变亮或模糊后为 60/60，位移后为 22/60。提示说明指标越过规则门限，不证明设备故障或原因正确；固定回放没有真实时间基准，不报告每小时告警率。原图正常组还会因检测窗口的 NG率提示产品变化，不能将综合规则提示直接当作独立成像检出率。

## AeBAD-S 本地入口

官方 Google Drive 下载在沙箱内外仍超时；天翼分享元信息可访问，但未获得图像，用户也没有本地数据。**AeBAD 尚未实测。** MVTec AD 2 已通过官方直接类别归档完成 vial 公共照明实验，当前方法零召回且各域样本不足；详细门槛与实测见[研发验收](vision-acceptance.md)。未用仓库演示 GIF 代替官方训练／测试集。

获得官方 AeBAD_S 本地目录后可执行：

```sh
python scripts/prepare_aebad.py --source /path/to/AeBAD_S --output data/public-datasets/aebad-bounded
python scripts/run_domain_study.py --source data/public-datasets/aebad-bounded --output artifacts/aebad-domains
```

入口读取 `train/good/*/*.png`，固定排序前 40 张拟合／后 20 张正常标定；test 中的 `same`、`background`、`illumination`、`view` 各保留最多正常／异常 30 张，不以标签选择处理方向。准备阶段验证两类存在、归一化像素不重复、路径边界、逐图摘要和原文件身份。摘要记录用户提供字节，不冒称权威发布摘要。评估使用原图 PaDiM，一次拟合与标定，各域保持同一阈值，报告可用分母及原图规则提示；不是官方 MMR 实现、像素定位指标或 PCB 现场验证。

## 本地视频与摄像头推理

安装可选视觉依赖、导出固定模型后，在“设置与演示”连接采集源，再在“本地模型”页的“本地视觉检测”填写模型目录，显式连接或重载。默认工作台仍使用无需 PyTorch 的演示代理。实际视觉模型在独立子进程中加载，单帧输入为 640×480 BGR；模型权重、统计、正常参考图和方法源码摘要均须匹配配方，旧方法配方须重新导出到新目录。

连接模型不沿用已有基线。先核验取景，再在“基线与漂移”采集 10–100 张正常工位参考图；这些图只建立图像观测与固定检测表现基线，不重新拟合 PaDiM 或调整其阈值。基线采集及逐图检测为暂停期间的串行操作，视觉失败／超时拒绝替换并保留旧基线。对待检物存在的声明仍为整帧 ROI 假设，没有目标定位模型或空场存在性保证。

连续观测时只允许一帧在途，不积累推理队列。采集提交后立即返回，后台轮询结果并对同一帧记录原图指标、异常分数与模型版本；状态查询及暂停不等待推理。暂停后已提交的一帧仍可完成留证，随后不再采集。未完成时拒绝重复单帧采样、源切换、基线替换或新回放，防止旧结果进入新配置。演示软件扰动在实时视觉模式禁用，应使用显式标记的视频或独立受控实验。

单帧时限 0.1–10 秒，默认 2 秒，从提交到后台观测计时，包含进程通信与轮询调度，不是模型纯计算时间。超时终止进程，当前帧标 `timeout`、后续帧保持 `error`，均无分数／判定；不能用上一帧或代理补齐。进程不可用须暂停后显式重载并重新建立基线；单帧对齐拒绝不杀进程，下一帧可重新推理。断流或视频结束暂停采集并保留错误；模型切回代理时同样清除基线。

工作台图像与成像规则仍使用原始采集像素。UI 的“检测观测耗时”包含通信和调度，现有“视觉处理”数值仅计后续观测与留证处理，二者不能混成摄像头完整延迟。视频标为“视频输入”，来源与实际缺陷需另行核验。

当前真实 ResNet18／PaDiM 在生成的 MJPG 视频中验证，内容为公开 PCB 图像、重复正常参考帧和独立合成空白帧；没有真实摄像头或产线采集，视频帧也不增加独立缺陷标签。摄像头使用同一检测路径，实际硬件取景、曝光、吞吐与长期运行仍待工位验收。

```sh
python scripts/serve_acceptance.py --port 8503
# 另一终端，专用实例使用临时数据库：
python scripts/test_visual_live_ui.py --url http://127.0.0.1:8503 --model /path/to/current-model --output artifacts/ui-visual-live
```

验收服务器仅 loopback，退出删除临时运行数据库，不覆盖默认证据。报告、截图、生成视频和本地模型不入 Git。

## 验证边界

姿态研究是固定参数的扩展评估，没有新基础模型、像素定位准确率或现场验收。独立模型统计重新加载时验证字段、形状、有限值、对称性、正定性和归档展开大小，不允许 pickle。方法来源与权重条款沿用[视觉检测](visual-detector.md)和[第三方说明](third_party.md)。
